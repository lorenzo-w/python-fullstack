# Python FullStack Docs

Welcome to the Python-FullStack documentation! 👋

This repository is intended as a template for turning ***pure Python modules*** (functions, classes, etc.) into ***full applications*** running both locally and on servers, thus enabling you to do *full-stack* development without having to worry too much about choosing and configuring all the tools for running and distributing your code (e.g. package managers, virtual machines, databases, webservers, domains, certificates, ...).

**Following are the main goals of this repo:**

1. Choose modern, well-maintained and fully open-source tools for all the needs of full-stack development.
2. Provide sane default configuration for these tools and their interoperability.
3. Allow developers to mainly work on the core logic of their program, outsourcing everything else to aforementioned tools and AI assistants.
4. Supply Ai assistants with high-quality context for working within this repo.
5. Visualize and (to some extent) enforce quality standards for first-party code and third-party dependencies.
